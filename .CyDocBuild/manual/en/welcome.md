## Open the Hub {#start}

On Windows, open **CyMCPHub.exe** and keep **CyMCPHubMcp.exe** next to it. On Ubuntu 24.04 x64, install `libcurl4t64`, extract the archive and start `./CyMCPHub`. Keep both Linux executables together.

Use **Sources** to choose a project or add a JSON, JSONC or TOML configuration file. Select a server by name, then select its connector to see its status, transport and connection data. Use **Refresh** after editing the source files.
